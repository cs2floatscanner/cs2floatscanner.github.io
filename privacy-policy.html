Privacy policy

How CS2 Float Scanner uses data for market scanning and Storage Unit management.

Updated 8 November 2026 · version 1.9.0

What the extension does

CS2 Float Scanner reads CS2 item data on supported Steam Market and inventory pages. Its optional Storage workspace signs in to Steam, reads your inventory and Storage Units, and sends only the item moves you choose.

Steam sign-in and session

QR authentication connects directly to Valve through Steam services and CM WebSocket servers. The extension does not ask for your Steam password. Steam identifiers, inventory data and Storage Unit contents are used locally to show your items and carry out the requested commands.

The Steam refresh token stays in memory in the open management tab. It is not saved to Chrome Storage or Chrome Sync, and is not sent to a developer authentication server. Closing or reloading the tab clears that local session. Signing out also requests revocation from Valve. Closing a tab alone does not guarantee removal of the authorized device from your Steam account; device authorizations can be managed in Steam.

Local storage

Chrome local storage holds display preferences, language, theme, float precision, pattern settings and public price caches. Storage price caches are separated by currency and are marked stale after six hours. Cached quotes remain local until cleared. Item selection and the active connection are handled in the management tab. Uninstalling removes extension local storage according to Chrome’s behavior.

Network requests

  • Valve / Steam: Steam pages, public price queries, item images, authentication, inventory data and the commands you request. Price queries use a public market item name and selected currency, without browser credentials.
  • GitHub raw content: the optional public sticker-price dataset. Private inventory data and Steam authentication tokens are not included in those requests.
  • Shields.io: a periodic request for the public aggregate Chrome Web Store user count. It does not submit your inventory or a per-user usage history.
  • Swap.gg: an optional external inspection link opened only when you choose it. The selected inspect link is passed to that service in the URL. Steam gallery images used for the supported PNG export flow load from Steam instead.
  • Telegram: channel and chat links open only when clicked. No Telegram widget is embedded and no automatic Telegram requests are made.

These services receive normal network metadata, such as an IP address, under their own policies. The extension is not an offline application. It does not include developer advertising trackers or a developer analytics backend.

Moves and public estimates

Transfer commands are sent directly to the CS2 coordinator. Transfers are sequential and wait for acknowledgement. An uncertain result stops the queue. Public prices are name-and-wear estimates; float, sticker and pattern premiums are excluded.

This website

This site is hosted by GitHub Pages. It serves static pages and locally hosted fonts. It saves only your selected website language in local storage and does not add advertising or analytics scripts. GitHub processes normal hosting request data under its own policies. Telegram links open only when you choose them; no Telegram widget is embedded.

Contact and control

You can close the Storage tab, sign out, clear public price caches in the workspace, or remove the extension. For questions, contact cs2floatscanner@gmail.com.

Что делает расширение

CS2 Float Scanner читает данные предметов CS2 на поддерживаемых страницах рынка и инвентаря Steam. Дополнительный модуль хранилищ выполняет вход в Steam, загружает инвентарь и хранилища, отправляет выбранные вами команды переноса.

Вход и сессия Steam

QR-авторизация выполняется напрямую через сервисы Valve и WebSocket-серверы Steam CM. Расширение не запрашивает пароль Steam. Идентификаторы Steam, данные инвентаря и содержимое хранилищ используются локально для отображения предметов и выполнения выбранных команд.

Refresh-токен Steam остаётся в памяти открытой вкладки управления. Он не сохраняется в Chrome Storage или Chrome Sync и не отправляется на сервер авторизации разработчика. Закрытие или перезагрузка вкладки очищает локальную сессию. При выходе также отправляется запрос отзыва токена в Valve. Одно лишь закрытие вкладки не гарантирует удаление авторизованного устройства из аккаунта Steam; управлять такими устройствами можно в Steam.

Локальное хранение

В локальном хранилище Chrome сохраняются вид интерфейса, язык, тема, точность float, настройки паттернов и кэш публичных цен. Кэш цен хранилищ разделён по валютам. Через шесть часов цены считаются устаревшими; сохранённые значения остаются локально до очистки. Выбор предметов и активное подключение обрабатываются во вкладке управления. Удаление расширения удаляет его локальные данные в соответствии с поведением Chrome.

Сетевые запросы

  • Valve / Steam: страницы Steam, публичные цены, изображения, авторизация, инвентарь и выбранные команды. Для публичных цен передаются название предмета на рынке и валюта, без учётных данных браузера.
  • GitHub raw content: дополнительный публичный набор цен наклеек. Запросы не содержат приватный инвентарь или токены Steam.
  • Shields.io: периодическая проверка общего публичного числа пользователей расширения в Chrome Web Store. Инвентарь и история действий конкретного пользователя не передаются.
  • Swap.gg: отдельная ссылка осмотра, открываемая только по вашему действию. Ссылка осмотра выбранного предмета передаётся этому сервису в URL. Для поддерживаемого экспорта PNG готовые изображения галереи загружаются из Steam.
  • Telegram: ссылки на канал и чат открываются только по нажатию. Встроенных виджетов и автоматических запросов к Telegram нет.

Сервисы получают обычные сетевые данные, например IP-адрес, и применяют свои политики. Расширение не работает полностью офлайн. В нём нет рекламных трекеров или сервера аналитики разработчика.

Переносы и оценки

Команды перемещения отправляются напрямую координатору CS2. Переносы выполняются последовательно с ожиданием подтверждения. При неопределённом результате очередь останавливается. Публичные цены оценивают предмет по названию и износу; надбавки за float, наклейки и паттерн не учитываются.

Этот сайт

Сайт размещён на GitHub Pages. Он загружает статические страницы, локально размещённые шрифты и демонстрационные снимки. В локальном хранилище сохраняется только язык сайта; рекламных и аналитических скриптов нет. GitHub обрабатывает обычные данные обращений к хостингу по своим правилам. Снимки не показывают приватный инвентарь реального пользователя или активный QR-код авторизации.

Связь и управление

Вы можете закрыть вкладку управления, выйти из сессии, очистить кэш публичных цен в интерфейсе или удалить расширение. Для вопросов: cs2floatscanner@gmail.com.
